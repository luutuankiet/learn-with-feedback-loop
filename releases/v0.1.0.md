# v0.1.0 — Initial release

First public cut of `gsd-mentor` — a personal programming-mentor agent built on the Karpathy LLM Wiki pattern, adapted for self-directed learning with cross-language bridges as a first-class artifact.

## What's in v0.1.0

- **Agent definition** (`.claude/agents/gsd-mentor.md`) — always-on mentor with the **Socratic + Dense** teaching philosophy. Each turn packs conceptual rationale, syntax tour, pseudo-code (punchline omitted), real-world production hook, cross-language anchor, and a substantive question. The mentor never spoon-feeds.
- **Four skills** for wiki operations:
  - `/mentor-ingest` — capture sessions into wiki pages with auto-trigger heuristics (solution complete, satisfaction signal, topic shift, natural rest point, explicit). User never types `/ingest` — agent fires on intent.
  - `/mentor-query` — search the wiki by index, follow `[[wikilinks]]`, synthesize with citations.
  - `/mentor-lint` — health-check for broken links, orphan pages, **concepts missing bridges** (high-leverage check), contradictions, stale claims.
  - `/mentor-bridge` — create explicit cross-language idiom maps (e.g. `python-global-vs-js-scoping.md`).
- **Schema** (`CLAUDE.md`) — single source of truth for the wiki structure, conventions, frontmatter, write discipline, and curation gate.
- **Vault scaffold** — `wiki/{concepts,bridges,exercises,synthesis}/`, `raw/sessions/`, `PROFILE.template.md`.
- **GitHub Actions release workflow** — tag-triggered releases reading from `releases/vX.Y.Z.md`.

## Design highlights

- **Flat markdown, no vector DB.** Vector RAG retrieves topically-similar but pedagogically-wrong chunks for learning use cases. Karpathy's index-driven pattern + Claude's long context handles a personal vault for years.
- **Anti-rot wiki discipline.** Wiki writes happen ONLY via `/mentor-ingest` (deliberate, batched, with confirmation). Mentoring turns are read-only on `wiki/`. PROFILE updates require explicit user approval.
- **Bridges are the novel layer.** Other tutors treat each language in isolation. For Python-fluent learners attacking JavaScript (or any analogous prior-fluency learner), `wiki/bridges/` is the highest-leverage doc type.
- **Privacy boundary in `.gitignore`.** The framework is public; your `PROFILE.md`, `raw/`, and `wiki/` contents stay local.
